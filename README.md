## stack

- compositor: mango
- bar: waybar (ironbar and eww configs (ᵕ•\_•) are unfinished/unthemed/unusable)
- launcher: walker
- notifications: mako, swayosd
- wallpapers: awww with a randomizer
- terminal / shell: kitty, zsh, starship, tmux
- files / editor tooling: yazi, bat
- music: mpd with rmpc and ncmpcpp
- apps: aerc, calcurse, taskwarrior, clipse, liferea, mpv

theming is tokyo night throughout, with tokyonight-dark gtk and dracula cursors.
